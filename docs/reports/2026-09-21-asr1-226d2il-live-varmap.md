# Живая сессия 226D2IL: финальная карта Setup-байтов + хауту (2026-09-21)

Продолжение разведки 2026-09-20 (docs/reports/2026-09-20-asr1-226d2il-setup-recon.md).
Атрибуция байтов в прошлый раз была снята с перепутанным тумблером — эта сессия
закрывает её живыми пробами: одно изменение в BIOS за ребут, полный слепок
efivars до/после, дифф, откат через efivar с проверкой. Стенд: asr1 (E3C226D2I,
P3.50), SOL-мост `hack/solrig.py` (лог-транскрипт навигации), ssh `root-asr1`.

## Хауту: как маппить поля конкретного BIOS

1. **Baseline — полный слепок efivars, не только Setup**: метод окупился сразу —
   Setup Prompt Timeout оказался в стандартной `Timeout`, угадать её по Setup-блобу
   невозможно.
   `hack/asr1-efivars-snap.sh s0-baseline` (все 69 переменных + плоская `Setup.bin`).
2. **Одно изменение за ребут** в Setup (F10). Навигация — под SOL-мостом: лог
   `/tmp/asr1-sol.log` пишет экраны и значения, можно сверять какой экран/блок.
3. ОС поднялась → `hack/asr1-efivars-snap.sh sN` →
   `hack/efivars-diff.py refs/amibcp/asr1-map/s0-baseline refs/amibcp/asr1-map/sN`
   (дифф печатает переменную, офсет по файлу и по данным с учётом 4B attrs).
4. **Откат**: `cat s0-…/Setup.bin > /sys/firmware/efi/efivars/…` (`chattr -i`),
   sha256-readback, `reboot` → проверка экраном в BIOS. Для SOL — self-verify:
   тумблер глушит UART, откат пишется вслепую по ssh, возврат POST в лог моста
   доказывает, что байт переключён верно.
5. Шум исключается списком известных переменных (ниже).

## Карта переменных (все значения подтверждены живыми flips)

| Меню BIOS | Переменная | Байт | IFR (899407D7…:0x18:0) | Значение |
|-----------|------------|------|------------------------|----------|
| Boot → Setup Prompt Timeout | **`Timeout`** 8be4df61-… | data[0], u16 LE | — (вне HII-форм) | секунды; вендор-дефолт 1, у нас 5 |
| Advanced → North Bridge → **Above 4G Decoding** | Setup EC87D643 | **data[1]** (обр. 0x500089) | форма **1215** «North Bridge Configuration», qid **0x13E**, off 0x1, w1 | 1=Enabled |
| Serial Port Console Redirection → **COM1** | Setup | **data[1140]** (0x5004FC) | форма 1158, qid **0x10B**, off 0x474 | 1=Enabled |
| → **SOL** | Setup | **data[1141]** (0x5004FD) | форма 1158, qid **0x10D**, off 0x475 | 1=Enabled |
| → **EMS** (Out-of-Band Mgmt/Windows) | Setup | **data[1156]** (0x50050C) | форма 1158, qid **0x10F**, off 0x484 | 1=Enabled; IFR-дефолт 1, NVRAM-дефолт 0 |

Маппинг: image-офсет = 0x500088 + data[N] (raw-тело StdDefaults, live↔image 1:1);
файл efivars = 4 байта attrs + данные (live[i+4] = std[i]).

## Поправки к разведке 2026-09-20

- **Неверно** было «SOL=data[1], 4G=data[1141]» — снятие с неправильным тумблером.
  Верно: **4G=data[1], SOL=data[1141]** (подтверждено независимыми flips).
- Формы **1025** (пустой заголовок, формсет 985EEE91) и **1035** «PCI Subsystem
  Settings» с prompt «Above 4G Decoding» — призраки, разделяющие строку с живым
  вопросом; live-экран = форма **1215**, qid **0x13E**. Тест-константа
  ASR1_4G_ITEM переведена на 1215:0x13E.
- Timeout живёт в стандартной переменной — не в Setup-блобе.

## Шум для диффов (не настройки)

- `MonotonicCounter-01368881` — тикает от любой активности прошивки.
- `SetUpdateCountVar-81c76078` — +1 на каждое сохранение Setup (F10); удобный
  маркер «сейв был».
- `HiiDB-1b838190` — внутреннее состояние HII-базы.
- `ConIn/ConInDev/ConOut/ConOutDev/ErrOut/ErrOutDev` — производные списки
  консолей: COM1→on добавляет COM1-UART (~+97Б на три переменные), SOL→off
  выкидывает SOL-UART; **EMS не влияет**.

## Наблюдения стенда

- **SOL=0**: мост «жив, но нем» — ipmitool-сессия не рвётся, лог замолкает на
  выходе из BIOS (ни POST, ни ОС). Откат вслепую по ssh + ребут → POST возвращается
  в лог (self-verify: замолк на 17:17, ожил на 17:18, +25КБ).
- **EMS=1**: мост работает всю загрузку (login в логе), Con* не меняются — EMS
  не претендует на BMC UART.
- **4G=0**: ssh/network выжили (сеть переведена с mlx4) — проба прошла без
  запасного пути.
- Полный efivar-откат Setup (1221Б) + ребут прошивка подхватывает на каждой пробе.

## Путь запекания дефолтов

`hii set-value` (StdDefaults, ин-плейс; чек-суммы пересоберёт движок):

```
899407D7-99FE-43D8-9A21-79EC328CAC21:0x18:0#1215:0x13E = 1   # Above 4G Decoding on
899407D7-99FE-43D8-9A21-79EC328CAC21:0x18:0#1158:0x10D = 1   # SOL on
899407D7-99FE-43D8-9A21-79EC328CAC21:0x18:0#1158:0x10B = 0   # COM1 off
899407D7-99FE-43D8-9A21-79EC328CAC21:0x18:0#1158:0x10F = 0   # EMS off
```

Setup Prompt Timeout — не HII-вопрос: печать только прямым NVAR-путём (в
StdDefaults вложена переменная Timeout, кандидат на nvar-op).

## Хвосты

- TUI: подпись EMS-блока в форме 1158 — два text-опкода (двухстрочный заголовок),
  движок экспортирует оба; TUI отрисовал подписи только COM1/SOL — кандидат на
  правку рендера.
- Проверка «третьего варианта» в TUI закрыта: третий блок = EMS, структура
  (вопрос + подформа 1159) на месте.
