# Отчёт: S4b — кандидаты E34/E35 (дискриминация виса E33)

> 2026-09-07, ветка `serial-console`. Прошивка — только владельцем.
> План `docs/superpowers/plans/2026-09-07-serial-s4b-term-discrimination.md`;
> вердикт E33 `docs/reports/2026-09-07-serial-s4a-e33-verdict.md`.

## 0. Новая гипотеза D (до дискриминации)

ConOut/ConIn — NV-переменные, **накопительные между прошивками**: к
буту E33 в ConOut уже лежал VT-UTF8-путь эры E32 (под TerminalDxe).
TerminalDxe в E33 удалён, но **TermSrc.Supported клеймит любой из 4
терминальных vendor-GUID** (вердикт §2-3) → консоль-инициализация
дёргает ConnectController по мёртвому пути → повторный TermSrc.Start
на том же порту; dedup-реестр @0x8E78 скипает только конфиг-чтение
(@0x229A), создание чайлда продолжается → второй чайлд / ошибка —
кандидат на ERROR DXE_BS_DRIVER и вис. E30–E32 сценария не
встречали: TerminalDxe обслуживал дубли путей корректно.
⇒ **первый бут E34 — только после CMOS/NVRAM-clear** (база чистая),
иначе D смешивается с A/C.

## 3. Протокол приёмки (руки владельца)

1. (хост выключен) **CMOS/NVRAM-clear джампером** — снести
   накопленные ConOut/ConIn-пути эры E30–E33 (гипотеза D).
2. Прошить **E34** → первый бут:
   - VGA: POST жив? Вход в Setup (DEL/F2) — входит или вис на
     «Entering Setup...»?
   - serial: тишина = норма (консоль не подключена); появление
     `ERROR: Class:…` — дословно в вердикт (RAW-принтер работает
     всегда — индикатор упавшего TermSrc.Start).
3. По дереву решений:

| E34 | E35 (если нужен) | Вывод |
|-----|------------------|-------|
| Setup входит, ERROR нет | шить: чисто ⇒ **D** (E33-вис = грязная ConOut; E33-повтор с чистым NVRAM = E36 по запросу); висит ⇒ **A/B** (glue×TermSrc) | TermSrc сам безвреден |
| Setup висит и/или ERROR | не нужен | **TermSrc токсичен сам по себе** (A/C): резерв (а) закрыт — путь (б)/патч рендера |

4. Все наблюдения — дословно в вердикт-отчёт S4b (даже «ничего не
   изменилось»).

## 4. Контингенси

- E34-вис: фиксируем смерть резерва (а) в спеке/roadmap (отдельный
  docs-коммит); возврат к терминальному рендеру через TerminalDxe
  (цвет = патч рендера, отдельная спека) или путь (б).
- E35-вис при E34-чистом: glue-v3-ревизия (по симптомам; кандидат
  v3.1 — без fallback-аппенда либо без ConIn-аппенда).
- E36 (= E33-цепочка на чистом NVRAM) — по запросу владельца, файлы
  и гейт s4a готовы.
