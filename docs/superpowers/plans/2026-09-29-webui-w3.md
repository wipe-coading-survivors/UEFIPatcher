# WebUI Parity W3 (NVRAM + Snapshots + Artifacts + добавление) Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Разделы NVRAM / Snapshots / Artifacts в WebUI + диалоги добавления в Forms (formset/form/question/page/hijack/export) — гейты W3: Playwright E2E на каждый блок (nvar-set ≡ CLI sha256-паритет; snapshot restore ≡ исходный образ; artifact download ≡ CLI export; question add ≡ CLI).

**Architecture:** Почти чистый фронтенд: все W3-RPC уже проксируются мостом `/api/v1/rpc/{Method}` (W1). Единственное Rust-изменение — REST `/api/v1/artifact/:id/download` (ArtifactExport в temp → binary stream, зеркало image-download). Компоненты по образцу W2 (runes, dumb-компоненты + колбэки, страницы-оркестраторы), числовые конверсии NVRAM — в чистом модуле `nvar.ts`.

**Tech Stack:** SvelteKit (SPA, adapter-static), Svelte 5.56 runes (`<svelte:boundary>` доступен), TypeScript, ts-proto типы (`forceLong=string`: uint64/int64 — `string`), vitest + @testing-library/svelte + msw, Playwright; Rust — axum gateway.

**Спека:** `docs/superpowers/specs/2026-09-28-webui-parity-design.md` (§W3 + аддендумы W1/W2).

## Global Constraints

- Rust-код: только Task 1 (artifact download route). Остальные 12 задач — только `webui/`.
- `npm run check` (svelte-check) и `npm run test` (vitest) — после каждой задачи; a11y-предупреждения = ошибки. После Task 1 — `cargo test -p uefi-gateway && cargo clippy -p uefi-gateway -- -D warnings`.
- proto3-JSON: `uint64`/`int64` → десятичная `string` (НЕ число, НЕ hex); `bytes` → base64-string; `map<string,uint32>` → JSON-объект. `bridge()` возвращает сырой JSON (без ts-proto runtime-декода) — поля bytes приходят как base64-строки, uint64 — как строки: для таких ответов определяем локальные row-типы (`nvar.ts` `VarRow`), а не ts-proto-типы.
- `optional string` в запросе (NvarSetRequest.guid): пусто → НЕ отправлять поле (ts-proto `guid?: string`; шлём `undefined`).
- Уроки W1 (аддендум спеки): тест-файлы страниц — `page.test.ts` (без `+`); msw-тесты — `server.listen/close`; svelte-рендер только с `svelteTesting()` (уже в vitest.config); `$app/navigation` закрыт alias-стабом; `Map`/`Set` в props нельзя.
- Уроки W2: keyed `{#each}` дубли ключей = silent-crash → все списки с first-wins дедупом ключей (vars `name#offset`, snapshots `snapshotId`, artifacts `artifactId`); union-аннотации на `$state` → `$state<T|null>(null)`; select `bind:value` инициализировать; негативные ассерты только `queryByText`; E2E: гвард `#status-session` до upload, каждому spec-файлу свой CLI-cwd, `test.setTimeout(300_000)`, `expect(sel.or(input)).toBeVisible()` до ветвления.
- Item-id конвенции (engine `hii/mod.rs` `parse_item_id`): форма = `<target>#<form_id-dec>`, вопрос = `<target>#<form_id>:<qid-hex-UPPER>`; раздел `forms.ts` (W2) уже экспортирует `formItemId`/`questionItemId` — переиспользовать, не дублировать.
- NvarSet-контракт движка: `offset`/`value` — uint64 (десятичная строка в JSON); UI принимает `0x`-hex ИЛИ decimal (NVRAM-офсеты естественно hex), нормализация — `parseNum` (`nvar.ts`, BigInt для hex→dec без потери точности). Движок сам валидирует диапазоны — UI не дублирует.
- Коммит-стиль: `feat(webui): … (спека webui-parity §W3)` / `feat(uefi-gateway): …`; дефекты плана — отдельный коммит `docs: fix Task N webui-w3 plan (…)` ДО реализации шага.

```rust
pub async fn artifact_download(
    State(state): State<AppState>,
    jar: CookieJar,
    Path(id): Path<String>,
) -> Result<Response<Body>, AppError> {
    let sid = extract_session_id(&jar).ok_or(AppError::Auth)?;
    let out_path = format!("/tmp/uefipatcher-artifact-dl-{}.bin", Uuid::new_v4());
    let mut c = state.client.lock().await;
    c.artifact_export(&state.sessions, &sid, &id, &out_path)
        .await
        .map_err(AppError::from)?;
    let data = tokio::fs::read(&out_path)
        .await
        .map_err(|e| AppError::Internal(e.to_string()))?;
    let _ = tokio::fs::remove_file(&out_path).await;
    Ok(Response::builder()
        .header(header::CONTENT_TYPE, "application/octet-stream")
        .header(
            header::CONTENT_DISPOSITION,
            format!("attachment; filename=\"artifact-{id}.bin\""),
        )
        .body(Body::from(data))
        .unwrap())
}
```

```ts
import { describe, expect, it } from 'vitest';
import { decodeBase64, hexDump, hexN, parseNum } from './nvar';

describe('nvar helpers', () => {
    it('decodeBase64 decodes standard base64', () => {
        expect(Array.from(decodeBase64('AQID'))).toEqual([1, 2, 3]);
        expect(Array.from(decodeBase64(''))).toEqual([]);
    });

    it('hexDump renders offset + hex + ascii rows of 16', () => {
        const bytes = new Uint8Array(18);
        for (let i = 0; i < 18; i++) bytes[i] = i + 0x41; // 'A'..
        const rows = hexDump(bytes);
        expect(rows).toHaveLength(2);
        expect(rows[0].startsWith('00000000')).toBe(true);
        expect(rows[0]).toContain('41 42 43 44 45 46 47 48  49 4A 4B 4C 4D 4E 4F 50');
        expect(rows[0]).toContain('|ABCDEFGHIJKLMNOP|');
        expect(rows[1].startsWith('00000010')).toBe(true);
        expect(rows[1]).toContain('|QR|');
    });

    it('parseNum accepts decimal and 0x-hex, normalizes to decimal string', () => {
        expect(parseNum('58')).toBe('58');
```

```ts
export interface VarRow {
    name: string;
    guid: string;
    offset: string;
    size: number;
    attributes: number;
    depth: number;
    data: string;
}

export function decodeBase64(b64: string): Uint8Array {
    if (!b64) return new Uint8Array(0);
    const raw = atob(b64);
    const out = new Uint8Array(raw.length);
    for (let i = 0; i < raw.length; i++) out[i] = raw.charCodeAt(i);
    return out;
}

export function hexDump(bytes: Uint8Array): string[] {
    const rows: string[] = [];
    for (let off = 0; off < bytes.length; off += 16) {
        const chunk = Array.from(bytes.slice(off, off + 16));
        const hexPart = chunk
            .map((b) => b.toString(16).toUpperCase().padStart(2, '0'))
            .join(' ');
        const padded = chunk.length <= 8
            ? hexPart
            : `${hexPart.slice(0, 23)}  ${hexPart.slice(24)}`;
        const ascii = chunk
            .map((b) => (b >= 0x20 && b < 0x7f ? String.fromCharCode(b) : '.'))
            .join('');
        rows.push(
            `${off.toString(16).toUpperCase().padStart(8, '0')}  ${padded.padEnd(
                16 * 3 + 2,
                ' ',
            )} |${ascii}|`,
        );
    }
    return rows;
}

export function parseNum(s: string): string | null {
    const t = s.trim();
    if (/^\d+$/.test(t)) return t;
    if (/^0x[0-9a-f]+$/i.test(t)) return BigInt(t).toString(10);
    return null;
}

export function hexN(n: string | number): string {
    const v = typeof n === 'number' ? BigInt(Math.trunc(n)) : BigInt(n);
    return `0x${v.toString(16).toUpperCase()}`;
}
```
